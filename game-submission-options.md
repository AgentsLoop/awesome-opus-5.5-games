# Where to submit a game

Choose a **publishing site** to host a playable build or create a game profile. Choose a **GitHub list** to propose a link to an already published game. Check each destination's current rules before submitting. No game has been submitted to these destinations as part of this comparison.

Verified on **2026-09-28** against the destinations' own documentation or contribution rules.

## Prepare a submission

1. Publish a working build or download page. Test its public link without relying on a private session.
2. Prepare a short gameplay description, controls, a cover image, and screenshots. Add a source repository and AI-development evidence when the destination asks for them.
3. Match the destination's format, licensing, and quality rules. Use its official form or contribution route; do not assume that a submission guarantees listing.
4. Track each submission URL and review outcome separately. Do not label an unsubmitted game as published on a destination.

Use the [verified awesome-list index](awesomelists.md) for collection sizes. Treat those counts as list entries, not submission or acceptance estimates.
