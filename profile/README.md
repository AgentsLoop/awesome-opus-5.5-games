# AgentsLoop

Explore open-source projects for building browser games with AI agents and discovering games made with them.

## Build

- **[OhMyGithub](https://github.com/AgentsLoop/OhMyGithub)** — Start a browser game or app project from a GitHub issue prompt. Use the repository to explore the agent workflow, tests, skills, and previews.
- **[PlayGround](https://github.com/AgentsLoop/PlayGround)** — Explore browser-game experiments.

## Discover

- **[Awesome AI Games](https://github.com/AgentsLoop/awesome-opus-5.5-games)** — Browse curated AI-built games with source repositories, model evidence, ratings, and screenshots.
- **[GPT Astra game collection](https://github.com/AgentsLoop/awesome-gpt-astra-games)** — Browse the companion collection of source-verified AI-built games, including GPT-6 Astra games.

## Get involved

Open an issue in the relevant project to report a problem, suggest an improvement, or share a game for review. Read that project's contribution guidance before opening a pull request.
