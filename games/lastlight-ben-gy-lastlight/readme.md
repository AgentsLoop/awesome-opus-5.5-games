## Source description

The README documents Lastlight as a playable browser settlement-survival game on a hex map. It includes a shrinking warmth ring, hearth homes, gathering huts, workshops, worker assignment, food/coal production, scouting, caches, stranded survivors, night resolution, three modes, scoring, solo play and a 2–6 player same-seed peer-to-peer race. The source includes the game, hex grid, mode rules, race flow and Canvas/DOM renderer; the repository contains a live GitHub Pages demo, Open Graph game image and tests for balance, contrast, rules, multiplayer lifecycle, rematch, takeover and UI. The cited initial gameplay commit contains an exact Co-Authored-By: Claude Opus 4.8 trailer. Count the settlement game once; exclude shared engine behavior.
