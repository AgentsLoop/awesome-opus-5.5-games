## Source description

The repository contains a C++/SFML/OpenGL native first-person voxel survival-extraction game. The game subproject includes CMake build files, terrain and chunk generation, camera and input, block mining and placement, inventory, crafting and smelting, weapons and arrows, health and stamina, procedural world systems, hostile pigman and spider AI, projectile collisions, dynamic difficulty, extraction rules, save/progression systems, shaders, models, textures, audio and five dated screenshots.
