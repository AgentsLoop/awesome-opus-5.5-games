The README describes a playable Godot 4 roguelite card game for iOS and Android, documents a Windows build, and states that the prologue runs end to end. game.tscn/game.gd provide the entry flow, battle.gd and combat_state.gd implement combat, and the minigame screens provide additional playable encounters.
