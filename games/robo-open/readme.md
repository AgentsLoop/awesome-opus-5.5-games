## Source description

The README identifies Robo Open as a playable Windows tennis prototype built with Unity and a largely autonomous Codex/GPT-6 Astra workflow. It documents serving, volleys, power/lob returns, net/out/double-bounce rules, scoring, CPU opponent, practice and competitive modes, persistent learning reports and a published Windows release. The repository contains the Unity project, C# controller, editable Blender assets, build scripts, tests, screenshots and validation receipts. The README states that no browser build is included. Classify under Non-Browser Engines.
