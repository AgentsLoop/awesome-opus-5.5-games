The README describes a native C++11 reverse-engineered Fruit Ninja port with arcade mode, fruit slicing, combo/frenzy behavior, 60 Hz simulation, settings, desktop/web targets and screenshots. The repository requires the user's own game data to run. The cited commit shows a direct Claude Opus 4.8 trailer.
