## Source description

The README explicitly describes a playable Unity demo built with Codex and GPT-6 Astra. The repository contains a Unity scene, C# simulation, runtime UI, traffic and pedestrian systems, shaders, audio, save/load, build scripts, screenshots and acceptance reports. The committed native macOS playtest passed with road construction, zoning, growth, save/load, moving vehicles and pedestrians, progression from 24 to 609 residents, and a working stadium; the report recorded 118 mean FPS on Apple M5 Pro at 1600×1000. Classified under Non-Browser Engines. No public browser build was claimed.
