## Source description

The public repository is a browser third-person action RPG inspired by The Witcher 3. It documents WASD movement, sprint stamina, dodge i-frames, light and heavy attacks, signs, lock-on, wolf combat, respawn and camera orbit. Source includes the game loop, player controller, test zone, Babylon/Havok setup, Vitest tests, Svelte HUD, Vite build and GitHub Pages deployment. The cited gameplay commit carries a direct Claude Fable 5 trailer. The live demo returned HTTP 200. Count the browser game as one unit.
