## Source description

The README explicitly states that GPT-6 Astra created this cooperative sheep-farming game one-shot in Codex. It documents the 16-step introduction, twelve sheep breeds, care, grazing, farming, construction, shared farms, inventory, chat and WebSocket synchronization. The repository contains a React Three Fiber frontend, Go game server, persistent storage, game rules, progression, source tests, a gameplay demo video and public deployment. Browser verification opened the live game, showed the farm landing page and reached the account-creation play flow; gameplay is account-gated, so no authenticated session was created.
