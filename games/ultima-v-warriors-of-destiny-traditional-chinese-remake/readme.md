## Source description

The public README describes a from-scratch Go/Ebitengine remake of Ultima V with a playable mainline, opening, world map, 32 locations, dialogue, shops, combat, magic, dungeons, music and the complete shrine-to-Shadowlords campaign. The repository contains the game entry point, combat scene, renderer, scene-map data, tests, cross-platform packaging and WebAssembly support. The cited commit carries a direct Claude Opus 5 co-author trailer. Count the remake as one game.
