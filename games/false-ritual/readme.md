## Source description

The README explicitly credits GPT-6 Astra in Codex for the playable Carter House prologue. It describes a first-person psychological horror game with exploration, environmental storytelling, interactive rooms, evidence, a pursuit-and-ritual sequence, movement, sprint, crouch, interaction, flashlight and focus controls. The repository contains a Godot 4.3 project, scenes, source, original assets, QA screenshots, documentation and a published v0.1.0 release with macOS and Windows ZIPs.
