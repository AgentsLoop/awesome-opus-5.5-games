## Source description

The README explicitly identifies a React/TypeScript/Three.js browser flight game powered by GPT6 and Hi3D. It documents a 180-second session flying through real sculpture apertures, movement in six directions, turning, acceleration, braking, collision, score rings, ten-second gate cooldowns, combo multipliers, pause, touch controls and a shared leaderboard. The repository contains the game API, physics/gate/combo methods, GLB assets, image references, tests, resource manifests, static checks and GitHub Pages workflow. Browser verification opened the public game and showed the sculpture flight screen, model loading state, GPT6 attribution, controls and +100 scoring instruction. Count GPT-6 as the qualifying Astra-era model label supplied by the repository.
