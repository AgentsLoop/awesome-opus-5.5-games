## Source description

The README identifies this repository as a Python/Pygame remake of Battle City. It documents 35 campaign stages, saved progress, endless 1P/2P waves, versus mode, a level editor, settings and difficulty presets, enemy AI variants, bonuses, gamepad controls, native Mac packaging and automated tests that start the game with dummy drivers. The source tree contains the entry point, game loop, tanks, levels, bonuses, screens and test suite. The cited September 11 gameplay-fix commit contains an exact Co-Authored-By: Claude Opus 5 trailer. No public live demo was claimed.
