## Source description

The README explicitly describes a playable first-person browser game built over roughly 24 hours with GPT-6 Astra. It documents captured Gaussian-splat worlds, movement, shooting, recoil, reloads, aim, crouch, jump, balls and an experimental zombie encounter. The repository contains a substantial PlayCanvas/WebGPU implementation with movement, ballistics, collisions, weapon state, levels, audio, HUD and zombie systems, plus a public GitHub Pages deployment. Browser verification opened the live launcher, showed level selection, WebGPU scene canvases, load controls, session controls and keyboard/mouse gameplay instructions; the build entered its scene-loading flow. Classified under Browser Games.
