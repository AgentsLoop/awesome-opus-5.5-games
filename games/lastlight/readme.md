## Source description

The repository is a two-world case study, but only LASTLIGHT is counted because its README explicitly labels it GPT-6 Astra; the companion Last Light Lancer is GPT-5.6 Sol and is excluded. LASTLIGHT is a fully playable local browser arcade game with a skiff, lighthouse protection, five tides, a Leviathan boss, auto-fire, upgrades, salvage, dash, shockwave, difficulty modes and saved best score. The repository contains the game source, download package, launcher, guide, manifest, validation record and offline browser instructions. Do not use the editorial cover as a gameplay screenshot; the README says it is not in-game. Classified under Browser Games.
