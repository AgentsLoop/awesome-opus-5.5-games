## Source description

The README describes a 2D pixel-art traditional Chinese medicine learning game with exploration, NPC dialogue, diagnosis, prescriptions, decoction, processing, casebook and planting systems. TownOutdoorScene provides world exploration, Player handles movement and the dedicated diagnosis/decoction scenes implement playable learning activities. The repository includes multiple gameplay GIFs; the cited commit includes an exact Co-Authored-By: Claude Opus 4.7 trailer.
