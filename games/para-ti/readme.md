## Source description

The repository contains a Vite/Phaser browser game with a title scene, outfit selection, four data-driven eras, top-down movement, collision, NPC dialogue, objectives, memory collection and an ending scene. EraScene implements the reusable gameplay scene and eras/index.js provides four world configurations. The cited implementation commit includes an exact Co-Authored-By: Claude Fable 5 trailer.
