## Source description

The repository is a newly created Unreal Engine 5.7 C++ pirate sailing combat game. README and source document a playable open-ocean loop with sail and rudder controls, wind-driven movement, AI enemy ships, broadside cannons, ballistic cannonballs, hull/rigging/rudder/battery damage, islands, grounding, convoy objectives, HUD and measured combat scenarios. DEVLOG records exact prompts and Claude Opus 5 / Claude Fable 5.1 attribution; the cited 2026-09-15 commit contains an exact Co-Authored-By: Claude Fable 5.1 trailer. Source files include ShipPawn, EnemyShipPawn, ShipAIController, CannonBall, Island, WindSubsystem, SeaGameMode and the Unreal map. Count one new native-engine game unit; no public browser demo was found.
