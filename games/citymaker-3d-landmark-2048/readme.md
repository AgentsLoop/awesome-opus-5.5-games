## Source description

The canonical repository is derek-wangpch/OpenCityMaker; the stale derek-wang/OpenCityMaker search result was rejected separately. The README describes a browser-based 2048 game with twelve cities, eleven tiers per city, 132 original procedural Three.js building models, scores, legal-move loss, 2048 win state, saves and match history. docs/CREATION.md explicitly records GPT-6 Astra generating the procedural geometry. Browser verification opened the live game and showed the playable Beijing board, score, 2048 progression, city selector, discovered/undiscovered buildings, movement controls and saved-progress state.
