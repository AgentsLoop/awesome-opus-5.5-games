## Apply the gate

- Require at least **15** distinct game entries.
- Count a game only when the list names a playable game or a game project.
- Exclude table-of-contents links, engines, libraries, assets, tutorials, tools, and contribution links.
- Preserve each list or collection repository as the source link. Do not replace it with a search-result URL.
- Recount when a list changes. Record the checked date in the change commit.
